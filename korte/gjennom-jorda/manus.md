# Gjennom jorda (TikTok-klipp av ArtiFyssik ep. 1)

Kilde: `Filmprosjekt/ArtiFyssik/TidGjennomJorda.mp4` (4K, uten tekst), beskåret til stående → `kilde.mov` (ikke i git).
Ferdig fil: `Filmprosjekt/ArtiFyssik/TikTok/`.

Oppbygning (utkast 1, 39 s): krok «Hvordan komme seg til Kina gjennom jordkloden?» → «suger bort all luft … antakelse» →
tegning 2× → «Gravitasjonskraften. Halleluja.» → regning 14× med forklaring (tyngden inni jorda virker som en fjær) →
«5068 s … del på to … ca. 42 min. Alt er 42.» → «Hvis dere fortsatt ikke har skjønt …» → sluttkort fysikkhjelp.no.

Lages med: `python3 tiktok.py` → `node rendre.js` → `python3 lyd_tt.py` → ffmpeg (grunn.mkv + overlay.mov + tt_lyd.wav).
